# hClient

A [JHenTai](https://github.com/jiangtian616/JHenTai) fork for E-Hentai and EXHentai, supporting Android, iOS, Windows and macOS.

## Client features

- Browse, search, favorites, watched galleries and history, with translated tags and filtering.
- Online and offline reading, with scrolling, paged and double-page layouts for phones, tablets and desktops.
- Gallery and archive downloads, automatic extraction, download priorities and groups, and local image reading.
- Account and Cookie login, comments, tag voting, ratings, torrents and biometric locking.

## Fork changes

- Fixed archive Range requests, with parallel downloads and resume where supported, and single-connection fallback otherwise.
- Added local and WebDAV backups for settings, login state and application data, with legacy import support.
- Added WebDAV gallery upload, automatic sync, cloud browsing, offline copies and local storage cleanup.
- Added gallery version grouping, shared file storage, metadata updates, editable groups, search, filtering and cloud statistics.
- Added lossless compressed image storage, fast reading and original-file export, plus image information in the reader.
- Improved transfer scheduling, connection reuse, upload speed display, Android background progress notifications and screen wake behavior.
- Refined gallery cards, responsive tabs, WebDAV settings and Android edge gestures; renamed the app and refreshed its icon.
